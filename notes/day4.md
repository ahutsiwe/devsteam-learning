# День 4 — .gitignore и GitHub

## Что такое удалённый репозиторий

Удалённый репозиторий — это копия моего репозитория на сервере GitHub. Локальный репозиторий живёт на моём компьютере, удалённый — в интернете. Они связаны через remote с именем origin.

## Push и pull

- `git push` — отправляет мои коммиты с компьютера на GitHub.
- `git pull` — забирает изменения с GitHub на компьютер.
- Первый push: `gh repo create devsteam-learning --public --source=. --remote=origin --push` — создал репозиторий на GitHub, подключил remote origin и запушил ветку master.

## Зачем нужен .gitignore

.gitignore — список файлов и папок, которые Git должен игнорировать, то есть не добавлять в коммиты и не отправлять на GitHub.

В моём .gitignore:
- `node_modules/` — папка с установленными пакетами, она огромная и её всегда можно восстановить командой установки, поэтому в репозиторий её не кладут.
- `.env` — файл с секретами (пароли, ключи). Секреты нельзя выкладывать в Git, особенно в публичный репозиторий.
- `*.log` — файлы журналов, они меняются сами и не нужны в истории проекта.
