# День 5 — Как работает веб

## Клиент и сервер

Клиент — это мой браузер. Он просит данные.
Сервер — это компьютер в интернете, который эти данные отдаёт.
Браузер сам сайты не хранит, он каждый раз запрашивает их у сервера.

## Запрос и ответ

Всё общение идёт так: браузер отправляет запрос, сервер присылает ответ.
У запроса есть адрес и метод, у ответа — код и содержимое.

## Методы GET и POST

GET — «дай мне»: просто получить данные. Открыть страницу, загрузить картинку.
POST — «вот данные, сохрани»: отправить форму, логин или комментарий. POST может менять что-то на сервере, GET — нет.

## Коды ответа

200 — всё хорошо, страница или файл отданы.
204 — тоже успех, но содержимого в ответе нет, возвращать нечего.
404 — не найдено, такого адреса на сервере нет.
500 — ошибка сервера, он сам сломался.

## Адрес страницы

Адрес состоит из домена, пути и параметров.
Например, github.com — это домен, имя сервера. После него идёт путь — что именно просим. После знака вопроса идут параметры — дополнительные данные.

## API

API — это договор между сервисами: один сервис просит данные у другого по заранее известным правилам и получает ответ, обычно в JSON.
Например, GitHub API отдаёт список репозиториев, а не страницу для человека.

## JSON

JSON — это текст с данными в виде пар «ключ — значение», списков и объектов.
Пример: {"name": "devsteam-learning", "public": true}
Его читает и человек, и программа.

## Мои запросы с GitHub

Открыл страницу https://github.com/ahutsiwe/devsteam-learning, вкладка Network, обновил страницу. Нашёл 3 запроса:

1. github.com — GET — 200. Браузер попросил главную страницу репозитория, сервер отдал её нормально.
2. github.githubassets.com — GET — 200. Браузер попросил файлы оформления и скрипты страницы, сервер отдал их нормально.
3. collector.github.com — POST — 204. Браузер отправил данные на сервер (телеметрия), сервер принял их, а возвращать в ответ ничего не стал — поэтому код 204.

## Результат дня

Понял, как браузер общается с сервером, что значат GET и POST, коды 200, 204, 404 и 500, что такое API и JSON.
