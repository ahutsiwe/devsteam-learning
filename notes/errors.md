# День 6 — VS Code вглубь и чтение ошибок

## Как читать сообщение об ошибке

У ошибки есть тип, текст, файл и строка. Читать нужно первую и последнюю строки, а не паниковать от всего вывода: первая строка говорит, что случилось, последняя часто подсказывает, как исправить.

## Что настроено

- Prettier — уже был установлен (esbenp.prettier-vscode), форматирует код.
- GitLens — установлен (eamodio.gitlens v19.6.1), показывает историю Git прямо в редакторе.
- Автосохранение — включено: `files.autoSave` = `afterDelay`, файлы сохраняются сами через короткую паузу после правки.
- Освоено: поиск по файлам, поиск по всему проекту, переименование файла из редактора, встроенный терминал.

## Ошибка 1 — несуществующая команда

Команда: `foobar-nonexistent-command-123`

Текст ошибки: `bash: line 1: foobar-nonexistent-command-123: command not found`, код выхода 127.

Причина: такой команды нет — я набрал выдуманное имя, и оболочка не нашла программу с таким названием.

Как исправил: проверил написание команды и что нужная программа вообще установлена, прежде чем запускать её снова.

## Ошибка 2 — чтение несуществующего файла

Команда: `cat C:/Users/lolsm/devsteam-learning/notes/no-such-file.md`

Текст ошибки: `cat: 'C:/Users/lolsm/devsteam-learning/notes/no-such-file.md': No such file or directory`, код выхода 1.

Причина: файла с таким именем в папке notes нет — я попросил прочитать то, чего не существует.

Как исправил: проверил список файлов в папке командой `ls` и убедился, что обращаюсь к существующему файлу и правильному пути.

## Ошибка 3 — опечатка в команде Git

Команда: `git statuz`

Текст ошибки: `git: 'statuz' is not a git command. See 'git --help'. The most similar command is status`, код выхода 1.

Причина: опечатка — написал `statuz` вместо `status`, такой подкоманды у Git нет.

Как исправил: прочитал подсказку в самом сообщении об ошибке — Git сам предложил похожее правильное слово — и запустил `git status`.

## Результат дня

Расширения Prettier и GitLens установлены, автосохранение включено, три ошибки вызваны намеренно и разобраны по форме: команда, текст ошибки, причина, как исправил.
